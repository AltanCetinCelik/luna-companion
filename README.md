# Luna Companion

A playful, memory-driven web companion experience built with React, TypeScript, and Vite. The project focuses on a lightweight interactive personality, responsive UI patterns, and a warm, emotionally expressive front-end.

## Highlights

- Interactive companion UI with a playful character loop
- Memory-based progress and relationship state
- Story and audio-driven moments
- Responsive layout for desktop and mobile
- Lightweight front-end architecture with Vite

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Getting started

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Production build

```bash
npm run build
```

This is an experimental front-end prototype designed for a charming companion experience. It is intentionally lightweight and easy to customize.
